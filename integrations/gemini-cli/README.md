# Gemini CLI Integration

- **Status:** `experimental`
- **Mechanism:** Agent Skills (`SKILL.md` discovery)
- **Project-Local Install Path:** `.gemini/skills/`
- **Global User Install Path:** `~/.gemini/skills/`
- **Limitations:** Gemini CLI is not installed in this build environment; adapter is marked `experimental` and requires `--force`.

## Install Commands

```powershell
.\install.ps1 --agent gemini-cli --scope user --force
```

```bash
./install.sh --agent gemini-cli --scope user --force
```
